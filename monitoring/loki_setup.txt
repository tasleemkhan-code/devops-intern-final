LOKI MONITORING SETUP NOTES (corrected)
=========================================

IMPORTANT CORRECTION FROM FIRST DRAFT:
Running `docker run ... grafana/loki` by itself is NOT monitoring.
Loki is only a log STORE — it does not scrape or pull logs from
anywhere on its own. Something has to actively read container logs
and PUSH them to Loki's API. That "something" is Promtail (the
log-shipping agent used here). Without it, Loki just sits there
empty. This file now documents the corrected, actually-working setup.

1. What's running
--------------------------------------------
docker-compose.monitoring.yml (in repo root) starts four containers:
  - loki       -> the log storage/query backend (port 3100)
  - promtail   -> the agent that discovers running Docker containers
                  via the Docker socket and ships their stdout/stderr
                  logs to Loki
  - grafana    -> UI for browsing/querying logs (port 3000)
  - hello      -> the app container from Step 3's Dockerfile, run in
                  a loop (see docker-compose.monitoring.yml comment)
                  so it keeps producing log lines instead of exiting
                  after one line

2. How it was started
--------------------------------------------
docker compose -f docker-compose.monitoring.yml up -d --build

3. How Promtail finds and ships the logs
--------------------------------------------
monitoring/promtail-config.yaml uses Promtail's docker_sd_configs
to talk to the Docker socket, auto-discover all running containers
(including hello-app), tail their logs, and push them to:
  http://loki:3100/loki/api/v1/push

This is the missing piece from the first draft of this file — it is
the actual log-collection agent, not just Loki running by itself.

4. Commands used to view/query logs
--------------------------------------------
Via LogCLI:
  logcli query '{container="hello-app"}' --addr="http://localhost:3100"

Via curl against the Loki API directly:
  curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
    --data-urlencode 'query={container="hello-app"}' | jq

Via Grafana (recommended, visual):
  1. Open http://localhost:3000
  2. Add a data source: Connections -> Data sources -> Add -> Loki
     URL: http://loki:3100
  3. Go to Explore, select the Loki data source
  4. Query: {container="hello-app"}
  5. "Hello, DevOps!" log lines should appear, refreshing every ~5s
